This map was created to show the locations of Berlin Conservatoires around 1900. The dataset containing the addresses was created by Marten Noorduin during the DFG-funded project ’You play exactly as if you came from America.’ Transatlantic Relations and Anti-American Bias in the Musical Life of the German Empire and the Austro-Hungarian Monarchy 1880-1915, hosted by the Musikhochschule in Lübeck, Germany, between 2022 and 2024. The map is referred to on page 188 of the following publication: Marten A. Noorduin, American Pianists and Anti-Americanism in Germany and Austria-Hungary around 1900 (The Boydell Press, 2026).

It's based on [Leaflet](https://github.com/Leaflet/Leaflet), an open-source JavaScript library for interactive maps. Using [Catmandu](https://github.com/LibreCat/Catmandu), JavaScript arrays for integration into Leaflet are generated from the XLSX file. Additionally, CSV and TSV files are created for publishing the historical research data.
